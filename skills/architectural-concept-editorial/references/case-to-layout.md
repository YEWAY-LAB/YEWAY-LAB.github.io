# 案例阅读与迁移

把参考文本视作证据组织方法，而非固定版式。分别记录页面任务、主证据、阅读次序、保护区、邻页关系、可迁移规则和不可复制元素。

| 设计任务 | 主要证据 | 可迁移机制 | 不可迁移内容 |
|---|---|---|---|
| 场地限制 | 原总图、红线、路网 | 完整底图主导，分层解释限制 | 其他项目的朝向、地块与数值 |
| 布局推导 | 同一基底的对照图 | 固定几何，每页改变一个有据变量 | 虚构历史演变 |
| 到达与空间序列 | 动线图、连续机位 | 从入口到公共空间逐站建立关系 | 不同项目的运营章节与文化符号 |
| 技术验证 | 原剖面、平面、计算 | 让技术证据决定读图尺度 | 其他项目的角度、面积或构造 |
| 建成结果 | 实景、施工记录 | 从整体到人体尺度核查设计回应 | 以摄影替代性能、验收或受力证明 |

迁移前写清：学习何种叙事动作、本项目哪幅原图支持、缺少何种资料、参考稿何种习惯应拒绝、与邻页何种对象建立联系。允许同基底逐页增加不同信息；禁止仅换标题或颜色重复。随机对调邻页、删除一页及更换项目名，检验内容是否仍然不可替代。

原项目、摄影、图纸、数字和私人资料不随本 Skill 公开分发；实际工作须使用获准的当前资料，并保留来源和署名。
