# v2.4 跨页叙事与视觉反模板门禁

## 五个失败信号

**F1 / 均质化**：每一页都是相同比例图片 + 同一块说明区；左右换位不构成新结构。

**F2 / 假推导**：用与实际总图、剖面无来源联系的曲线/箭头/色块充当设计操作。

**F3 / 主题展览而非逻辑链**：页与页只是“场地、屋顶、结构、材料”话题切换，没有“为什么下一页必需出现”的证据推进。

**F4 / 小图强排**：图纸内容本身细小，仍为了满足模块尺寸将技术图压缩到无法阅读；应反过来降低文字密度扩大真实图纸。

**F5 / 伪作品册**：照片不错但每张照片配相似口号，编辑图版不能精确关联建筑体量、尺度或路径。

## 六项检查动作

1. 先生成一版不含色彩和字的图像墙，人工按1秒阅读次序逐页编号。
2. 统计每页的主图占比与侧栏占比，不要求比例不同，但应为其内容来源作出解释。
3. 检查连贯三页中是否出现2次以上同类图片—文字二分语法；触发时先从素材和论证关系重新组织，不能只换底色。
4. 对照片进行主体保护区校验（屋顶、入口、地平线、主建筑完整性）。
5. 对技术图明确标出“由哪个真实图纸及图号直接支持”，检查原图与新稿裁切。
6. 输出“视觉审稿失败页/为什么失败/如何改故事板”的独立审稿意见，不能靠字体自动缩小解决。

## 视觉评分（人工辅助，不是可替代主观设计审查的客观标准）

| 维度 | 分值 | 判据 |
|---|---:|---|
| 真实建筑信息的递进 | 0–25 | 每页新增建筑事实、设计操作或可核验空间证据 |
| 图证与标题之间的精确对应 | 0–25 | 图不可以任意替换；相邻因果关系明确 |
| 页面语法的必要性与跨页节奏 | 0–20 | 式样变化来自图证性质，不是轮播模板 |
| 原图比例、字体和图纸清晰度 | 0–15 | 不裁断、不模糊、不缩字；母版完整 |
|克制的图文编辑与来源处理|0–15|没有无功能图框、卡片、色带、过饱和图像|

任一建筑真实性红线未过，即使总分很高也不合格。70分以下回到故事板；70–85分进入重点精修；85分以上仍须人工审定，不得宣称等同任何事务所专业作品。
