# v2.5｜反模板拒收：审稿优先于所谓“国际化风格”

## 阶段退回规则

| 错误 | 识别信号 | 退回阶段 | 不充分的修复 |
|---|---|---|---|
| R1 主题图册 | 随机交换页序并不影响理解 | S2故事板 | 调色、加页码 |
| R2 图证替换性 | 换任意同类型建筑照文字仍成立 | S0/S2证据与标题 | 把标题加粗 |
| R3 同一页面语法占比过高 | 7页中4页以上“单大图＋窄边栏” | S3构图 | 左右互换、黑白换肤 |
| R4 把图纸挤成图标 | 原图轴线、尺寸无法辨认 | S3图证优先 | 在图下注一行“详见原图” |
| R5 假轴线/错位索引 | 总图、剖面、摄影无法建立点位关系却画箭头 | S0工程事实 | 加“概念示意”掩饰具体误导 |
| R6 直接贴旧PPT | 旧标题栏、页码、来源与图片一起进入像素 | S3原片提取 | 在上面叠新标题 |
| R7 图像假深化 | 生图新增玻璃、绿化、结构节点等 | S0几何保护 | 多迭代几次同模型 |
| R8 一味追求每页不同 | 页型多变但设计证据没有连续 | S2故事板 | 再增加一种版式 |
| R9 过度反重复 | 连续推演原本应复用同一真实底图，却用不同伪图替换 | S0/S2 | 禁止所有重复图像 |
| R10 无功能留白 | 大块空白没有建立层级和停顿且内容空泛 | S3构图 | 添加金句、背景纹样 |

## 人工三道门禁

1. **去字看图**：去掉标题与正文，主图和图纸的连续性是否能反映同一个建筑问题？
2. **去图看逻辑**：留下短标题与相邻页连接，是否形成可陈述的具体设计机制？
3. **走进建筑**：从整体到剖面再到体验，是否交代了视点与尺度关系？不得无证据声称点位一致。

## 字体与图片取舍

- 方案汇报需要在远距离投影中可阅读的主结论；正文因屏幕与版式调整，但不得以“网页信息密度”作为正当化小字号的理由。
- 主要建筑图完整优先；如需局部放大，优先有可核实部位的建筑近景，而不是随意裁原图构造做“放大节点”。
- 大图如已具足够表达能力，文字可以少；技术页若图纸很复杂，宁可一页只保留一幅真实图。只允许有目的的“呼吸”，不为7页配额硬塞虚张页。
- 黑底/白底/局部项目色不预先规定配额，依材料与阅读目的选择。不接受装饰性短线、彩色角标、过饱和大字/卡片作为自动风格。

## 自动检查的局限

图像面积分布、PPT元素越界、OCR/字体、图片哈希只能提示“可能重复”或“可能模糊”。它们看不见真实的建筑设计意图，也不自动验证点位与工程事实。运行全部脚本仍需设计总监逐页视觉审查；失败样本需要保留，而不是用平均分掩盖。
