# 建筑学文案标准｜v2.6

## 文案基本原则
建筑方案文本应像有证据的设计讨论：用空间、构造、程序、性能的明确关系代替抒情修辞。每页文字必须能被图纸、原始资料或可验证比较支持。文案允许有观点，但不允许把个人阅读写成方案史事实。

**优先表达结构**：对象＋空间/技术动作＋与问题的关系＋来源或适用范围。

不利于方案评审的写法（须人工复核，不是机械删除一切类似词）：

| 容易空泛的表述 | 适合评审的表述 |
|---|---|
| 建筑与自然诗意对话，塑造有温度的校园 | 学院教学区设置方形院落，宿舍区设置环形院落，构成不同围合度的室外空间 |
| 让知识在流动中生长，构筑未来学习共同体 | 连接教学单体的连廊与庭院提供公共步行与非正式交流空间；具体使用强度尚待测量 |
| 绿色科技全面赋能建筑，开启可持续新篇章 | 图书馆绿色专项设计资料列示外窗开启面积比例37.39%，属于设计阶段指标，不能替代运行实测 |
| 以巧妙的结构回应场地精神，形成震撼体验 | 在原剖面中可见多层中庭与阅览空间的竖向联系；结构尺寸需以施工图为准 |
| 立面形式完美诠释理性与感性 | 格栅、窗洞与廊道构成遮阳和视线过滤的外部界面；实际遮阳效果需结合朝向和专项计算判断 |

## 禁止的表达误差
- 拟人化、诗化标题泛滥："城市的呼吸"、"建筑的灵魂"、"让空间生长"、"用设计赋能未来"、"打造地标"，除非明确来自用户原始正式设计概念且正文有可核对图证。
- 所谓金句替代事实；缺图纸时写“显然”“必然”“完美”“全部”“最大”“首次”等绝对结论。
- 用“全生命周期绿色建筑”替代具体运行数据；以设计模拟结论代替后评价。
- 读图方向和轴线未确认却给出具体方位、米数或箭头。
- 从同一张摄影图推定设计团队确切方案生成顺序。
- 混同项目整体、建筑组团与某一单体的建筑规模和性能。

## 推荐审稿方式
1. 圈出每句的建筑名词：院落/连廊/剪力墙/双层幕墙/视线/采光/疏散等，不够具体则返工。
2. 给每个动词找对象：围合什么、连接哪两个空间、遮挡什么、比较何种方案、如何验证？
3. 在页边标注事实类型 SOURCE_FACT / EDITORIAL_INFERENCE / DESIGN_PROPOSAL。正式PPT只展示经审核的内容，不带内部标签。
4. 不成立时删减、拆页、回源，不靠润色补充事实。
