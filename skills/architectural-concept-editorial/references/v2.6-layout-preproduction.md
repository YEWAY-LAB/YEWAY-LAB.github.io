# 版面预策划｜在绘制任何正式页面前

1. **选证据**：优先总图、平立剖及真实建成摄影。明确什么信息仅能由图纸回答、什么仅能由照片证明；性能必须使用指标来源，不能由摄影推断。
2. **先排跨页节奏**：从总图建立地理坐标，再转向局部院落、人行空间、单体剖面与材料界面。要有图纸主角页、整体摄影页、比较页、剖面页、读图页，不为了避免重复强行切换。
3. **为每页指定主视觉任务**：全页建筑实景、原图主导、同源图局部比较、技术条带、竖向照片与指标等，均应因证据而发生，不能成为重复套版。
4. **锁定比例与主体**：技术图必须等比例；场地关系、北向、图例与建筑标注不能误裁；照片不拉伸、重点构件不切头；同图反复使用时清楚记录新变量。
5. **书写密度适中**：标题尽量一句；结论短而有建筑对象；材料/指标/图例注解需可读。不以大标题、小图标和空白填补专业信息不足。
6. **线框先审**：输出全页视觉墙，标注P01…、每图资源ID、裁切方向、临近页面的阅读桥梁、缺素材警示。至少做跨页灰阶、图片比例、正文点大小三轮人工审查。

示例（非固定版型）：项目总平P02以图纸为主、数据置于可读边缘；P03在同一总平上对读方院与环院；P04深入教学空间；P06转环形生活院落；P08放大图书馆的专业剖面；P10以真实立面配绿色专项数字。视觉变化必须服从这些阅读任务。
