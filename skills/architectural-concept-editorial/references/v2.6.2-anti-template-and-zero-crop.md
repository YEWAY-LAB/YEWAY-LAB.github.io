# v2.6.2：反模板编辑与建筑原图裁切禁令

## 失败案例：校园示例 R3（2026-10）

R3 采用黑白体系，却反复排列“统一大标题—固定图片框—说明侧栏/灰框—通栏页脚”。这依然是PPT模板，不是建筑学编辑。照片被代码使用 `cover` 填入与原图长宽比不符的框：步行照片被裁去约60.7%（P04）和32.7%（P05）、宿舍照片35.5%（P06）、中庭照片51%（P08）、立面照片19.1%（P09）。数字由影像长宽比和画框比例计算，非视觉分割精测。

## 制作前必须完成原图构图卡（Image Composition Card）

每次出现图片记录：`asset_id / source_version / evidence_role / original_aspect / protected_content / intended_viewport_aspect / crop_fraction / fit_strategy / edit_auth / crop_authorized / why_this_page`。

1. **原始图纸默认 ZERO CROP。** 总平、平面、剖面、立面、轴测、节点、文字图例不许用 cover 插入固定画框。若另页用局部放大，必须保留“完整原图所在页”或清楚注明“同源局部”，且不得伪造新几何。
2. **建筑摄影默认 ZERO CROP。** 整体建筑、城市环境、屋顶、基座、建筑群、场地、对称/透视轴线、连廊与行人视线等均为证据主体。不得为了16:9满铺自动牺牲主体。缺失现场上下文时不得以局部图冒充整体。
3. **只有明确论点的局部解析可例外。** 例外需标明保留的对象、显示的同一来源完整图片和局部视框、裁切损失百分数，人工核准后才能进入正式生产；未审核，不是默认许可。
4. **不拉伸、不扭曲、不修补建筑**；自然摄影保留原始色彩。缺合适横图就让照片按自然比例排版，换机位/换图或降低图幅，而不是剪掉屋顶与入口。
5. **照片裁切面积门禁**：默认 `crop_fraction = 0`。若源文件已是有目的的同源局部，可用完整局部图展示，但其源图派生关系必须标识。非0裁切必须有“用户审批 + 证据ROI”两项记录。即便是微小裁切，也不因自动测试未报错而无条件放行。

## 从内容到版面：不是搜图后塞入固定矩形

G1按建筑问题分配论点及原始证据。G2首先按图片原生长宽比、必须可见的建筑部分和图纸可读性决定版面比例，**最后才加文本**。对每页问：删掉大标题/边栏/数字后，这张图是否还在准确解释建筑？若无，内容未成立，不通过构图审稿。

## 反模板强制检查

- 禁止每页复用相同的页顶标题、页底识别条、左图右文、灰框插图、编号卡和机械黑白交替。
- 章节格式没有配额；根据原始照片、图纸性质形成节奏：鸟瞰保完整环境、总图作阅读面、局部对读、通廊摄影保透视、宿舍竖构图保基座与屋顶、剖面宽幅保完整、立面竖幅保材质边界、最后可用纯字图证清单。以上是**针对不同资产的具体例子，不是新模板清单**。
- 三页连续出现相同图文位置关系且无建筑论点差异时，自动列为返工。含大型标题、固定图片框和页码页脚的统一外壳超过半数时，整套直接拒收。
- 排版依赖实际图片关系而不是向每一页填统一 `x,y,width,height`。系统检查必须读取图片实际比例、视觉可见内容、跨页图文节奏；无裁切也不等于必然好看。
- 允许图片复用，只要每一次复用服务新的空间比例、定位或对照结论。禁止机械追求“图不重复”造成错误证据或无关照片填充。

## G2交付与审批门禁

提交**素材墙 + 整组缩略墙 + 至少两页原图大图审读 + 画像保护清单 + 布局重复风险清单**。用户未批准G2，不允许生产正式PPT。`scripts/audit_image_crops.py` 的0裁切证明为必要条件，不能替代建筑师判断。

检查连续页面是否重复同一种版式，并核对完整原图与局部放大用途。项目审阅样张不随公开版分发。
